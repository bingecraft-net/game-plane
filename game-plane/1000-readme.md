# Game Plane

Game Plane is the best way for community stewards to run game servers like Monifactory, Valheim, and Astroneer.

Stewards apply game server changes to git Helm.

Game Plane receives game server changes from git Helm and applies them to game servers.

Home labs can get started right away.

The development configuration is good enough to play throwaway worlds.

Prerequisites include Kind and Argo CD CLI.
