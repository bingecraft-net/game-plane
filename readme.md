# game-plane

> Game Plane is the best way for community stewards to run game servers like Monifactory, Valheim, and Astroneer.

- [Stories](https://github.com/bingecraft-net/stories/tree/main/game-plane/1000-readme.md)

## Quick Start

Install Game Plane CLI dependencies:

```bash
./install.sh
```

This installs Homebrew (if needed), then Argo CD CLI, kubectl, and Ansible.

Then verify:

```bash
ansible --version
```
