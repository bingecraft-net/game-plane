# 1003: Run

One command to get a game server running on your infrastructure.

## Run

After bootstrap, the CLI deploys a game server with one command:

```
gameplane run --chart valheim-server --world my-valheim-world
gameplane run --chart monifactory-server --world my-monifactory-world
```

## What Happens

1. **Helm chart selected** — Game Plane picks the right Helm chart for the game (`valheim-server` or `monifactory-server`)
2. **World configured** — The specified world name is passed to the Helm chart
3. **Argo CD deploys** — Argo CD applies the Helm chart to the Kind cluster
4. **Game server starts** — The game server software is installed/configured
5. **Status** — surfaces Argo CD's reconciliation status through the CLI

## Git Repository Structure

Add server charts to the `game-servers/helm-charts/` directory:

```
game-servers/
├── inventory/
│   └── hosts.yml          # Server inventory (Ansible)
├── helm-charts/
│   ├── valheim-server/
│   │   ├── Chart.yaml
│   │   ├── values.yaml      # Default config
│   │   └── templates/       # Helm templates
│   └── monifactory-server/
│       ├── Chart.yaml
│       ├── values.yaml      # Default config
│       └── templates/       # Helm templates
```

## Expected User Flow

```
gameplane bootstrap --repo git@github.com:user/game-servers
gameplane run --chart valheim-server --world my-valheim-world
gameplane status
gameplane stop --chart valheim-server --world my-valheim-world
gameplane debootstrap
```

## Acceptance Criteria

- [ ] One command deploys a game server with configurable world name
- [ ] Helm chart is selected based on game type
- [ ] World data persists outside the cluster lifecycle
- [ ] CLI reports game server status (running, stopped, error)
- [ ] Game server can be stopped and restarted without data loss
